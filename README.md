# DeepSeek 批量提问助手 v2.0

## 📖 项目简介

本项目是一个基于 **CustomTkinter** 和 **Selenium** 的自动化工具，旨在批量向 **DeepSeek** 或 **豆包** 等 AI 模型提问，并将模型的答案自动写入 Excel 文件。  
支持断点续传、跳过规则、截图留存、日志筛选等高级功能，适用于需要大量调用 AI 模型进行数据标注、内容生成、问题批量处理等场景。

## ✨ 主要特性

- ✅ **多模型支持**：可切换 DeepSeek / 豆包，不同模型在“模型设置”标签页中自动显示对应的模式控件（DeepSeek 的快速/专家、深度思考/智能搜索；豆包的快速/思考/专家）。
- ✅ **批量提问**：从 Excel 读取问题列（和可选的上下文列），自动逐条发送并获取回答。
- ✅ **断点续传**：已获得回答的行会自动跳过，中断后可继续执行。
- ✅ **跳过规则**：根据某列的值（如 `bad`）自动跳过行，并标记为 `SKIPPED`。
- ✅ **前缀指令**：支持在每次提问前附加公共指令，并提供常用指令预设（可增删改查）。
- ✅ **截图留存**：自动保存填入提示词、点击发送、开始输出、回答稳定等关键步骤的截图，并可在右侧“截图历史”区域查看、双击放大。
- ✅ **日志系统**：所有运行日志以按钮形式显示在左侧，支持按“处理进度/模型回答/系统报错/普通信息”多选筛选，并可自动滚动。同时日志会写入 `logs/` 下的文本文件。
- ✅ **信息面板**：实时显示 Excel 输入文件、输出文件、当前日志目录的路径，点击即可打开所在文件夹。
- ✅ **界面自适应**：窗口大小、位置、最大化状态自动保存；界面可整体缩放（在“浏览器配置”标签页中调整 `set_widget_scaling`）。
- ✅ **配置持久化**：所有设置（包括模型平台、模式、跳过规则、预设指令、窗口几何等）均自动保存到 `deepseek_config.json`。

## 🔧 安装与依赖

### 1. 安装 Python 3.8+ 环境

### 2. 安装依赖库

建议使用虚拟环境，然后执行：

```bash
pip install customtkinter pandas openpyxl pillow selenium webdriver-manager
```

- `customtkinter` – 现代化 GUI 框架
- `pandas` & `openpyxl` – Excel 读写
- `pillow` – 图片处理（截图预览）
- `selenium` – 浏览器自动化
- `webdriver-manager` – 自动管理 ChromeDriver

> 注意：项目未使用 `requests` 或官方 API，完全通过浏览器模拟操作，因此需要安装 Chrome 浏览器。

## 🚀 使用方法

### 1. 准备 Excel 文件

- 必填列：问题列（如 “问题”）
- 可选列：上下文列（如 “历史对话”），用于双列模式
- 跳过列（如 “分工”），配合跳过规则使用
- 输出文件会自动增加 “回答” 列，用于存储模型返回的内容

示例表格：

| 问题 | 分工 | 回答 |
|------|------|------|
| 1+1等于几？ | good | (自动填充) |
| 编写一个排序函数 | bad | (会被跳过，标记 SKIPPED) |

### 2. 启动程序

```bash
python main.py
```

### 3. 界面操作说明

#### 基础配置标签页

- **Excel 文件**：选择输入文件（支持 `.xlsx` / `.xls`）
- **输出文件**：指定结果保存路径（若相同，执行时会自动添加时间戳防止覆盖）
- **加载列名**：加载表头，用于填充上下文列、问题列、跳过列的下拉菜单
- **启用上下文**：勾选后可使用双列模式（历史对话 + 当前问题）
- **前缀指令**：固定附加在每个提示词前面的公共指令
- **常用指令**：预设若干常用前缀，支持插入、保存当前、编辑、清空

#### 模型设置标签页

- **模型平台**：选择 `DeepSeek` 或 `豆包`
  - DeepSeek：模式（快速 / 专家）、深度思考、智能搜索
  - 豆包：模式（快速 / 思考 / 专家）

#### 高级功能标签页

- **启用跳过规则**：勾选后可根据某列的值自动跳过行
  - 跳过列：选择判断依据列
  - 跳过值：逗号分隔，如 `bad,skip,废弃`
  - 跳过标记：自动填入回答列的标记（默认 `SKIPPED`）
- **跳过登录**：勾选后直接执行，不再等待手动登录（适用于已登录过且保留会话的情况）

#### 浏览器配置标签页

- **窗口模式**：最大化 / 最小化 / 自定义（宽、高、X、Y）
- **界面缩放**：调整整个 GUI 的缩放比例（0.8 ~ 1.5）

#### 右侧监控区域

- **日志列表**：每条日志为可点击按钮，点击后显示详细信息和图片
  - 自动滚动复选框：控制新日志是否自动滚动到底部
  - 筛选按钮：弹出多选窗口，按类别过滤日志
- **截图历史**：所有截图按时间顺序堆积，每个截图带行号标题、缩略图，可单独删除或一键清空
- **信息面板**（日志列表下方）：显示当前输入/输出文件路径、日志目录路径，点击可打开文件夹

#### 底部按钮

- 🚀 **开始执行**：启动工作线程，自动打开浏览器并执行提问
- ⏹ **停止执行**：中断当前任务
- ✅ **确认已登录**：手动登录后点击，自动化继续（若未勾选“跳过登录”）
- 🔧 **清理 Chrome 进程**：强制结束所有 Chrome 进程（解决残留进程问题）

### 4. 首次运行与登录

- 启动任务后，程序会打开浏览器并跳转至对应平台（DeepSeek 或豆包）。
- 如果您未勾选“跳过登录”，程序会等待您手动登录账号，然后点击界面上的“确认已登录”按钮。
- 登录后浏览器窗口会自动移到屏幕外（避免干扰），自动化操作在后台进行。
- 每次运行会在 `logs/` 下创建带时间戳的子目录，保存所有截图和详细日志。

## 📝 配置文件说明

`deepseek_config.json` 自动保存以下设置：

- `excel_path`, `output_path`, `prefix`, `enable_context`, `context_col`, `question_col`, `context_label`, `question_label`
- `browser_mode`, `browser_width`, `browser_height`, `browser_x`, `browser_y`
- `skip_login`, `enable_skip`, `skip_col`, `skip_values`, `skip_mark`
- `preset_prefixes` (常用指令字典)
- `active_filters` (日志筛选的多选列表)
- `model_platform` (DeepSeek / 豆包)
- `mode`, `deep_think`, `smart_search` (DeepSeek 特有)
- `doubao_mode` (豆包特有)
- `window_geometry`, `window_maximized`

> 您可以直接编辑该文件，但修改后请确保 JSON 格式正确。

## ❓ 常见问题

### 1. 提示“未找到选择器”或豆包模式切换失败？

豆包网页的 DOM 结构可能更新。请根据实际页面调整 `worker.py` 中的 `_doubao_set_mode`、`_doubao_send`、`_doubao_wait_for_answer` 方法里的 CSS 选择器或 XPath。建议在浏览器中打开 F12 开发者工具，定位到对应的按钮和消息框元素，修改相应代码。

### 2. 跳过规则不生效？

- 检查“高级功能”标签页中“启用跳过规则”是否勾选。
- 确认“跳过列”已通过“加载列名”选择正确的列名。
- 检查“跳过值”是否与单元格内容完全匹配（区分大小写，无额外空格）。

### 3. 日志筛选后左侧显示异常？

- 已使用 `pack` 方式重新构建日志按钮，并强制更新 `scrollregion`，一般不会出现问题。如果偶尔出现内容收缩，可尝试切换“自动滚动”或点击“筛选”按钮重新应用筛选。

### 4. 如何更换界面字体种类？

默认使用系统 UI 字体。如需更换（如宋体），可在 `gui.py` 的 `__init__` 开始处添加：
```python
ctk.FontManager.load_font("simsun.ttf")
ctk.set_default_font(("SimSun", 12))
```
但需要确保字体文件存在，且跨平台兼容性不佳，故未内置。

### 5. 截图太多占用磁盘怎么办？

程序会自动清理旧的日志目录（默认保留总大小不超过 20MB）。您也可以手动删除 `logs/` 下不需要的子目录。
